- **Widgets mounted (kit `c558bea`, branch `f13ld-wave1-kit`):** 5 segmented (source, Library tiling, Builder tiling, snap density, edit mode), 2 dropdowns (topology with a live rebuild for pushed cells, symmetry relabelled), 3 sliders (radius, Builder radius, cell size), 1 clip radio, 5 view-menu toggles, sections rail + tab bar (replace the stage 2 fallback tabs, which stay as the no-WebGL fallback). Native inputs stay hidden as the state source; `matE`, `matNu`, `bldCellName`, Undo / Redo / Clear and the action buttons stay native.
- **Wire is the template unchanged except `CONFIG`.** Differences on purpose: (1) it runs from a `DOMContentLoaded` listener, because beam builds the view menu in its own `DOMContentLoaded` handler and the wire needs those checkboxes; (2) the template's header block (Recipe menu mounts, Mesh / Lab / Queue hiding) is left out of the inlined `f13ui-style` until stage 5, with `.fh-mesh-btn[data-native=send]` forced visible meanwhile; (3) `script#f13ui-beam` adds two bits of beam glue: help "show" switches Library / Builder first, and Draw collapses the phone sheet.
- **Help "show"** uses the wire's `CONFIG.helpTargets` pointing at the `.sc-group` rows (the hidden natives have no box). The old stage 2 `f13ui-help-show` block stays only as the no-WebGL fallback and does nothing when widgets are mounted.
- **Phone drawing:** the sheet is a separate pane below the viewer, so at peek (45 % of the height) the whole viewer stays uncovered. Entering Draw (Builder) from a full sheet now collapses it to peek (743 → 380 px at 390×844); the viewer is 369 px tall. Two taps on snap points added one beam; 11 of 12 on-screen snap points are hittable (one sits under the sheet handle). Undo / Redo / Clear and the status line are below the fold at peek and scroll.
- **Stage 5 reminder:** `CONFIG.recipe` is `null`; set it (mode-aware `exportBtn` needs a function, not an id: template gap) and re-add the template header CSS block when mounting the Recipe menu.

## Decisions (Matt, 2026-11-25)

Shared, all wave 1 tools:
- **Quality:** automatic, as in TPMS. Remove the manual quality control (buttons or slider); its help (i) goes with it.
- **Stale analysis:** clear homogenization / stiffness results when the design changes, and on import. Exports carry results only for the current design.
- **Missing help cards:** add them; the (i) count rises by that number (record the new count).
- **Field sliders that re-bake:** show a low-res preview bake while dragging, full bake on release. Keep it only if it measures faster to first change than today and does not slow the full bake.
- **Accent:** derived from the tool colour in the F13LD brand guidelines v2.0 (hue kept, lifted to L 0.80 for the dark UI). Final value pending Matt.

This tool:
- **Accent (proposed):** olive-lime `oklch(0.80 0.15 121)` ≈ `#afcc54`, from brand stroke `#4A5A0F`. Close to the brand neon `#c8f542` used by TPMS; lower chroma if it reads the same.
- **Quality buttons:** removed (automatic). Pixel-ratio cap to 2 comes with the render-quality pattern.

- Library / Builder becomes a choice inside Cell. Recipe menu (Export JSON / Queue / Mesh / Lab) sends the Builder cell on Builder. LTCX and CSV in the Recipe menu. DPR cap 2. Ghost preview always on (checkbox removed). Cell size slider moves next to export. Import restores E_s / ν_s.
